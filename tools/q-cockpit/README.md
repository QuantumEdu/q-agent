# q-cockpit — Visual Socratic Grill & Mission Cockpit for q-agent

> **Zero-Node Native Python Runtime** · Single-port HTTP/REST/UI server · Compatible with `jasonku09/grill-with-ui` session protocols and `unclebob/swarm-forge` observability patterns.

---

## Overview

`q-cockpit` provides an interactive web cockpit and execution monitor for `q-agent`. It unites two critical capabilities into a single lightweight service:

1. **Socratic Grill & Elicitation (P04 / `q-grill-me` / `grill-with-ui` pattern)**:
   - Visual card deck for architectural questioning.
   - Live rendering of interactive HTML prototypes or Mermaid architecture diagrams (`visual.html`).
   - Batch staging of user answers before committing to disk.
   - Non-blocking agent waiting: agents invoke `q_cockpit.py wait` or listen on `events.jsonl`.

2. **Mission Cockpit & Multi-Agent Observability (SwarmForge pattern)**:
   - Real-time **TDD Task Kanban** (Backlog / In Progress Red-Green / Completed).
   - **Quality Gate Semaphores (P03, P04, P08)** with Human-in-the-loop Approve/Reject triggers.
   - **Git Workspace Health**: live tracking of branch status, porcelain dirtiness, and recent commits.

---

## Key Architectural Advantages

- **Zero Node.js, Zero npm, Zero Build Step**: Runs directly via the Python 3 standard library (`http.server`, `socketserver`, `json`, `subprocess`). No dependencies, no virtual environments required.
- **Hermetic File-Based State**:
  - `~/.q-cockpit/sessions/<project-key>/<timestamp>/`
    - `state.json`: Managed by the orchestrator / agent.
    - `events.jsonl`: Append-only event stream generated by user interactions in the browser.
    - `visual.html`: Live prototype or diagram served at `/visual`.
- **Fast Startup**: Bootstraps in less than 50ms on WSL / Linux.

## Usage & CLI Commands

### 1. Launch the Web Cockpit
```bash
# Launch inside any project (defaults to port 4242)
python3 tools/q-cockpit/q_cockpit.py serve

# Specify a custom port or project root
python3 tools/q-cockpit/q_cockpit.py serve --port 5050 --project /path/to/repo
```

### 2. Create a New Elicitation Session
```bash
python3 tools/q-cockpit/q_cockpit.py new --topic "Authentication Refactoring" --doc docs/auth-design.md
```

### 3. Agent Integration (Wait for Human Input)
When an agent reaches a gate or needs interview answers, it runs:
```bash
python3 tools/q-cockpit/q_cockpit.py wait --session ~/.q-cockpit/sessions/<project-key>/<session-id> --timeout 300
```
This blocks until the human clicks **"Enviar Respuestas"** or decides a gate in the web UI, returning the recorded events on stdout.

## REST API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/` | Serves the interactive cockpit SPA |
| `GET` | `/api/status` | Complete JSON snapshot of project, session, tasks, and gates |
| `GET` | `/visual` | Serves `visual.html` or placeholder |
| `GET` | `/api/diff` | Returns `git diff HEAD` of the active project |
| `POST` | `/api/grill/answer` | Records staged answers into `events.jsonl` and updates `state.json` |
| `POST` | `/api/gate/action` | Records an approval or rejection for P03, P04, or P08 gates |
| `POST` | `/api/grill/add_question` | Appends a new probing question from the agent |
| `POST` | `/api/session/new` | Spawns a fresh session directory |
